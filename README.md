# 🌟 HappyPulse - Your Daily Dose of Positive News

A beautiful, simple website dedicated to sharing positive, uplifting news that makes you feel good about the world. Built with pure HTML, CSS, and JavaScript - no frameworks or complex dependencies.

## ✨ Features

- **🎉 Positive News Feed**: Curated collection of heartwarming, inspiring stories
- **📱 Responsive Design**: Works perfectly on all devices
- **🏷️ Category Filtering**: Filter news by Science, Environment, Health, Community, Technology, and Education
- **💭 Mood Tracker**: Share how the news makes you feel
- **🎊 Interactive Elements**: Fun animations and confetti celebrations
- **🔍 Easy Navigation**: Smooth scrolling and intuitive design

## 🚀 How to Use

1. **Open the website**: Simply open `index.html` in any modern web browser
2. **Browse good news**: Scroll through the positive news articles
3. **Filter by category**: Click on any category card to see specific types of news
4. **Load more**: Click "Load More Good News" to see additional articles
5. **Track your mood**: Click on mood buttons to share how the news makes you feel
6. **Easter egg**: Click the logo 5 times for a surprise! 🎉

## 🛠️ Customization

The website is built with simple, clean code that's easy to modify:

- **Add new news**: Edit the `positiveNews` array in `script.js`
- **Change colors**: Modify the CSS color variables in `styles.css`
- **Update categories**: Add new categories in both HTML and JavaScript
- **Modify layout**: All styling is in the well-organized `styles.css` file
